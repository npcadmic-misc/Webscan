## 系统介绍

Web漏洞扫描系统是一个功能完整的Web应用程序安全测试工具，支持多种类型的漏洞检测。

### 主要功能

- **基础扫描**：检测OWASP Top 10常见漏洞（SQL注入、XSS、CSRF等）
- **深度扫描**：检测越权访问、业务逻辑漏洞、敏感信息泄露
- **API扫描**：检测REST API和GraphQL接口的安全问题
- **多格式报告**：支持HTML和Markdown格式报告
- **插件系统**：可扩展的插件架构
- **双界面模式**：同时支持CLI和Web界面

## 安装指南

### 环境要求

- Python 3.8+
- Node.js 16+
- Windows/Linux/macOS

### 后端安装

```bash
cd backend
pip install -r requirements.txt
```

### 前端安装

```bash
cd frontend
npm install
```

## 快速开始

### CLI模式

1. 进入backend目录
2. 运行 `python cli.py`
3. 按照提示输入目标URL和配置
4. 等待扫描完成并查看报告

### Web模式

1. 启动后端：`cd backend && python -m app.main`
2. 启动前端：`cd frontend && npm run dev`
3. 浏览器访问 http://localhost:3000
4. 在界面上配置扫描任务并开始扫描

## 功能详解

### 创建扫描任务

1. 点击"开始扫描"或访问 `/scan` 页面
2. 输入目标URL
3. 选择扫描类型（基础/深度/API）
4. 可选：配置认证信息（Cookie/Token）
5. 可选：调整高级配置（并发数、速率限制等）
6. 选择报告格式（HTML/Markdown）
7. 点击"开始扫描"

### 查看扫描历史

1. 点击"查看历史"或访问 `/history` 页面
2. 查看所有已完成的扫描任务
3. 点击"查看报告"查看详细信息

### 生成报告

1. 扫描完成后自动保存报告
2. 可在历史记录中重新下载报告
3. 支持HTML和Markdown两种格式

### 系统设置

访问 `/settings` 页面可以：
- 调整默认扫描配置
- 管理插件
- 配置报告选项

## 常见问题

### Q: 扫描速度慢怎么办？

A: 可以在高级配置中增加并发数和速率限制，但要注意不要对目标服务器造成过大压力。

### Q: 如何减少误报？

A: 
- 使用深度扫描模式进行更精确的检测
- 手动验证发现的漏洞
- 标记误报以便系统优化

### Q: 支持哪些认证方式？

A: 目前支持Cookie、Token和Bearer Token三种认证方式。

### Q: 如何扩展扫描功能？

A: 可以通过插件系统添加自定义检测模块，详见开发者文档。
