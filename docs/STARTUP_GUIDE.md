## 🔍 环境检测

### Windows用户

双击运行 `check_env.bat` 进行完整的环境检测。

### 检测项目

该脚本会检查以下内容：

1. **Python环境**
   - Python是否安装
   - Python版本是否>=3.8
   - pip是否可用

2. **Node.js环境**
   - Node.js是否安装
   - Node.js版本是否>=16
   - npm是否可用

3. **项目依赖**
   - 后端依赖（FastAPI、httpx、psutil等）
   - 前端依赖（node_modules目录）

4. **系统资源**
   - 端口8000和3000是否被占用
   - 可用内存是否充足
   - 磁盘空间检查

### 检测结果说明

- ✅ `[OK]` - 检查通过
- ❌ `[FAIL]` - 检查失败，需要修复
- ⚠️ `[WARN]` - 警告，可以忽略但可能影响功能

## 🚀 启动系统

### 方式一：批处理文件（推荐）

双击运行 `启动系统.bat`，会打开一个交互式菜单。

### 方式二：PowerShell脚本

```powershell
cd <项目根目录>
.\start.ps1
```

### 启动选项说明

#### [1] 仅启动后端 (FastAPI)

- **适用场景**：只需要API服务，或使用其他前端/客户端
- **访问地址**：
  - API: http://localhost:8000
  - API文档: http://localhost:8000/docs
- **停止方法**：在后端窗口按 `Ctrl+C`

#### [2] 仅启动前端 (Vue开发服务器)

- **适用场景**：后端已在其他地方运行
- **访问地址**：http://localhost:3000
- **前提条件**：需要先启动后端，否则前端无法调用API
- **停止方法**：在前端窗口按 `Ctrl+C`

#### [3] 同时启动后端和前端 ⭐推荐

- **适用场景**：完整使用系统的所有功能
- **访问地址**：
  - 前端界面: http://localhost:3000
  - 后端API: http://localhost:8000
  - API文档: http://localhost:8000/docs
- **特点**：
  - 后端在独立窗口运行
  - 前端在当前窗口运行
  - 关闭任意窗口都会停止对应服务
- **停止方法**：关闭所有相关窗口

#### [4] CLI模式扫描

- **适用场景**：快速扫描单个目标，无需图形界面
- **操作流程**：
  1. 输入目标URL
  2. 选择扫描类型（基础/深度/API/全部）
  3. 配置认证信息（可选）
  4. 调整高级参数（可选）
  5. 开始扫描
- **输出**：扫描完成后报告保存在 `data/reports/` 目录

#### [5] 检查服务状态

- **功能**：
  - 显示后端服务是否运行
  - 显示前端服务是否运行
  - 显示端口8000和3000的占用情况
- **用途**：诊断服务是否正常启动

## ❓ 常见问题

### Q1: 双击 `启动系统.bat` 后闪退？

**A:** 可能是PowerShell执行策略限制。解决方法：

1. 以管理员身份打开PowerShell
2. 运行：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
3. 重新运行 `启动系统.bat`

### Q2: 提示"Python未安装"或"Node.js未安装"？

**A:** 
1. 确认已安装相应软件
2. 确认已添加到系统PATH环境变量
3. 重新打开命令行窗口测试：
   ```bash
   python --version
   node --version
   ```

### Q3: 端口被占用怎么办？

**A:** 
- 方法1：关闭占用端口的程序
- 方法2：修改配置文件中的端口号
  - 后端端口：`backend/app/main.py` 最后一行
  - 前端端口：`frontend/vite.config.js` 中的 `port`

### Q4: 前端启动失败，提示"找不到模块"？

**A:** 
```bash
cd frontend
npm install
```

### Q5: 后端启动失败，提示"ModuleNotFoundError"？

**A:** 
```bash
cd backend
pip install -r requirements.txt
```

### Q6: 如何查看详细的错误日志？

**A:** 
- 后端日志：`data/logs/app.log`
- 控制台也会实时显示错误信息

### Q7: 扫描速度慢怎么办？

**A:** 
- 在扫描配置中增加并发数
- 提高速率限制
- 只选择需要的扫描类型

### Q8: 如何在后台持续运行服务？

**A:** 
Windows可以使用任务计划程序或nssm工具将服务注册为Windows服务。
